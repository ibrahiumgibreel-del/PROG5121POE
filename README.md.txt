# PROG5121POE Part 1

This Java console application allows a user to register and log in.

## Registration requirements

- The username must contain an underscore and may not exceed five characters.
- The password must contain at least eight characters, a capital letter, a number and a special character.
- The cellphone number must use the South African +27 international code.

## Testing

JUnit 4 tests are included to test valid and invalid usernames, passwords, cellphone numbers and login details.
